# PV Power Forecasting

This repository contains the code and results for a CS229 (Machine Learning) project focused on photovoltaic (PV) power forecasting. The project implements and evaluates various time series forecasting models, including FDNet and linear regression approaches, to predict solar power output across multiple prediction horizons (1, 6, 12, 24, and 48 hours ahead). The models utilize weather and temporal features to forecast PV power generation, with comprehensive evaluation metrics and visualization tools included.

For detailed methodology, results, and analysis, please see the `Write Up` folder.
